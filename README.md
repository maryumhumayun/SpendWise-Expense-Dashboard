# SpendWise – Personal Expense & Budget Dashboard

SpendWise is a browser-based personal finance management application developed to help users track their income, expenses, and monthly budgets.

## Features
- Add, edit, and delete transactions.
- Track total income, expenses, and remaining balance.
- Set monthly budgets and receive budget warnings.
- View spending through interactive charts.
- Filter transactions by date, category, type, and month.
- Export transaction records to CSV.
- Print or save reports as PDF.
- Includes 100 sample transactions across multiple months.

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Use
Open the live website in a browser or download `index.html` and open it locally.

## Project
Developed as an academic project to demonstrate web development and personal finance management concepts.
